## TextFilterAppliction

Console app that read file with .txt and apply 3 filters follow:
1. Remove words that have lessthan 3 charecter
2. Remove words that not contain vowel in the middle
3. Remove words that contain letter 't'

## How to run
cd src/TextFilterApp
dotnet run

## How to run UnitTest
cd tests/TextFilterApp.Tests
dotnet test
