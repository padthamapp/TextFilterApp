## TextFilterAppliction

Console app for read .txt file and apply 3 filters by:
1. Remove words that have less than 3 charecters.
2. Remove words that not contain vowel in the middle.
3. Remove words that contain letter 't'.

## How to run
cd src/TextFilterApp
dotnet run

## How to run UnitTest
cd tests/TextFilterApp.Tests
dotnet test
